How to Run the Project - خطوات تشغيل المشروع

1. Database Setup:

Open XAMPP and start Apache & MySQL.

Go to phpMyAdmin and create a new database named: smart_pricing_db

Import the SQL file located in the Database folder.

2. Backend Setup (Python/Flask):

Open CMD inside the Backend folder.

Install requirements: pip install -r requirements.txt (or install manually: flask, flask-cors, pandas, scikit-learn, pymysql, cloudscraper, bs4, google-generativeai).

Run the server: python app.py

3. Frontend Setup (React/Vite):

Open a NEW CMD inside the Frontend folder.

Install packages: npm install (or pnpm install)

Run the website: npm run dev

Open the provided Localhost link in your browser.
